### ANPR Toll Processing System
End-to-end Automatic Number Plate Recognition system with a full PostgreSQL relational schema covering vehicle ownership, RFID tags, toll transactions, fine management, and security incident tracking. Includes properly indexed foreign key relationships, cascade rules, and lookup tables.

→ [github.com/Zain-ul-Abdin45/ANPR-Toll-Processing](https://github.com/Zain-ul-Abdin45/ANPR-Toll-Processing)

### JWT & OAuth2 in FastAPI
Production-grade authentication and authorisation implementation covering token construction, scope enforcement, refresh token rotation, and Redis blocklist for logout. Includes bcrypt password hashing, typed token claims to prevent token confusion attacks, and HMAC vs RSA signing comparison.

→ [Medium article](https://medium.com/@zainkhoso45/jwt-oauth2-in-fastapi-from-token-construction-to-scope-enforcement-5b3852cdc4b4) · GitHub: coming soon

### Urban Vitality Survey Pipeline (Lödige Industries)
End-to-end survey analytics pipeline for a city centre performance study covering 53 decision-makers. Python-based ETL into PostgreSQL, statistical analysis with Matplotlib, findings delivered through a stakeholder presentation and a Power BI dashboard for ongoing monitoring.
